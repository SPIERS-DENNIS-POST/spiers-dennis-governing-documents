The Constitution and Bylaws are separate UTF-8 plain-text (`.txt`) files, intended to be readable and reproducible directly from their source without Markdown or HTML formatting. Line breaks and blank lines organize the text but do not recreate the scanned page layout. Git still records line-by-line diffs and historical versions. Both transcriptions were compared page by page with the signed scan on November 19, 2026, but have not received independent proofreading or formal verification. The scan controls if a transcription differs. Neither the scan nor this repository establishes that no later amendments were adopted. Editorial status, provenance, and interpretation notes belong in this README rather than the `.txt` files.

## Guidance for amending

**Amendments are made by the Post, not by GitHub.** Legionnaires introduce motions and the Post considers and votes on them at its meetings, following Robert's Rules of Order and the applicable Constitution, Bylaws, and higher governing requirements. Members do not need to know GitHub to participate.

GitHub serves a different purpose: **an observable record of changes to the published governing text.** Once an amendment has been adopted, the repository maintainer can open a pull request showing the exact approved changes to the canonical plain-text documents. The diff makes every addition and deletion visible. The pull request's description and discussion can explain the change and identify the motion, adopting meeting, official minutes or resolution, and effective date. This commentary accompanies—but does not replace—the Post's official records.

The maintainer checks that the proposed merge reproduces the wording actually adopted, then merges the pull request into `main` to publish the updated text and generate new printable or other copies. Git history preserves the earlier wording and the change.

A technically inclined member may open a pull request before a meeting, but that does **not** place a motion before the Post or approve an amendment. The ordinary meeting procedure still controls, and no unadopted wording is merged as governing text.

**Standard operating procedures (SOPs)** are different. They are the Post Executive's operational playbook and may be revised in the ordinary course within the Executive's authority. They cannot conflict with the Constitution, Bylaws, or applicable Department, National, or other higher authority; they do not require the constitutional amendment workflow simply because they are stored in this repository.

## Repository privacy
**This repository must be created Private.** While Private, its issues, pull requests, commits, and diffs are not public. Before any later conversion to Public, review **all prior Git history and discussions** for information that should remain confidential. The publishing script refuses to upload to a repository reported by GitHub as public.
## Authenticity and retention
Git history supplies useful traceability, not definitive proof of legal adoption and not a tamper-proof archival system. Preserve the historical scan, signed records, adopted minutes, backups, and any records required by Colorado law and Legion rules. Formally adopted, applicable governing documents control—not the most recent draft commit.
